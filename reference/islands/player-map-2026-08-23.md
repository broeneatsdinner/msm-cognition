## Usage

- Use this map when creating dated screenshot batch folders.
- Locked islands should not be expected to have inventory screenshots.
- Empty unlocked island folders may still be intentional if inventory tracking is
  not currently useful for that island.
- Use full island names exactly as recorded here, especially for Mirror islands.
- A future TUI or website should show map progress beside each island when
  present, separately from Book page variant totals and current owned counts.
