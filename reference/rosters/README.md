# Island rosters

This directory is for island-specific monster rosters: the monsters that can
ever appear on each island.

Roster data is separate from player inventory and current limited-time
availability. It should be derived from stable sources such as official
*My Singing Monsters* pages, the *My Singing Monsters* wiki, checked-in
reference exports, and validation against the user's Book screenshots.

## Files

```text
plant-island.md   Plant Island roster; Rares confirmed in game 2026-10-29
```
