# Ethereal Islets reference

Reference notes on the Ethereal Islets (Plasma, Mech, Shadow, Crystal) on the
Mirror map, the Dish-Harmonizer structure, Dish Wishes, Primordials, and
Rarethereals.

```text

```

## Source policy

Facts are tagged by source so future sessions know how far to trust them:

- **Help Center** — official Big Blue Bubble support articles
  (`bigbluebubblesupport.helpshift.com`). Treat as official, but some articles
  are old (the islet teleport and unlock articles were about 589 days old when
  read).
- **Wiki** — My Singing Monsters Wiki (Fandom). Community-maintained. Odds
  tables are community research, not developer numbers.
- **User** — stated by the player in chat (for example current sale prices).

Last researched: 2026-10-01.

Chrome browser tools.
